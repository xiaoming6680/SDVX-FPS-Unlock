# 发布

Release 只上传用户需要的 3 个文件：`install.bat`、`install.ps1`、`README.txt`（`release/README.txt`，含双语说明和 MIT 许可证全文）。
GitHub 自动附带的 Source code 压缩包删不掉，用户下载我们上传的 zip 即可。

```powershell
powershell -ExecutionPolicy Bypass -File tools\build-release.ps1 -Version v1.1.0
gh release create v1.1.0 dist\SDVX-FPS-Unlock-v1.1.0.zip --title v1.1.0 --notes-file <说明文件>
```

`dist/` 已在 `.gitignore` 中。发布前在模拟目录里跑一遍 `install.ps1`：正常安装、重复安装、特征码对不上三种情况。
